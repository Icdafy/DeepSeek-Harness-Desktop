# DeepSeek Harness v0.0.3

本次版本内置 Aqua 透明 UI 插件，并优化应用图标的圆角显示。

## 下载选择

- **Setup**：`DeepSeek-Harness-Setup-0.0.3-x64.exe`，适合日常安装和后续自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.3-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 内置 [`dsh-client-ui-aqua@1.3.1`](https://github.com/WYH66666666/DSH-Transparent-UI-Plugin)，首次启动时从安装包离线部署，不需要用户另装 Node.js、Git 或执行联网脚本。
- Aqua 默认启用，可在 **Settings → Plugins → Glass theme** 中关闭；外观参数位于 **Settings → General → Appearance**。
- 支持 Mica 磨砂玻璃、兼容模式、流体背景、自定义壁纸、背景亮度、模糊度与粒子鲸鱼等设置。
- 白底鲸鱼图标改为透明圆角底，避免在桌面、开始菜单和任务栏中呈现生硬的正方形白块。

## 更新说明

已开启“自动接收桌面更新”的 v0.0.2 用户会通过 GitHub Releases 收到本次更新，也可以手动下载安装包覆盖升级。原有配置、会话和插件设置会保留。

本版本尚未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从本仓库 Releases 下载并核对 SHA-256。

本项目是社区桌面封装，不是 DeepSeek 官方桌面客户端，也不代表 DeepSeek 官方背书。
