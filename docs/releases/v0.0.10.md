# DeepSeek Harness v0.0.10

Windows x64 桌面版：消除顶部标题栏与主页面之间的背景色差。

## 本版修复

- 移除顶部标题栏独立叠加的底色、模糊与阴影，抹平横向接缝。
- Aqua 模式下，标题栏直接透出已有的全窗口背景，流体背景与壁纸连续显示。
- 普通主题下，标题栏使用与主页面相同的背景色；切换深浅主题时同步窗口控制按钮颜色。

## 下载

- **Setup**：`DeepSeek-Harness-Setup-0.0.10-x64.exe`，支持覆盖安装和自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.10-x64.exe`，免安装启动。
- **SHA256SUMS.txt**：安装器和便携版的 SHA-256 校验值。
- `latest.yml` 与 `.blockmap`：供已有桌面客户端自动更新使用。

内置 Harness 版本继续为 `0.1.5-rc.1`。原有模型配置、工作区、对话记录和外观设置继续使用原用户数据目录。

本项目是社区维护的桌面封装，不是 DeepSeek 官方桌面客户端。
