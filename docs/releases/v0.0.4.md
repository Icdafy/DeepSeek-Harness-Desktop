# DeepSeek Harness v0.0.4

本次版本修复外观与窗口状态在重启后恢复默认的问题。

## 下载选择

- **Setup**：`DeepSeek-Harness-Setup-0.0.4-x64.exe`，适合日常安装和后续自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.4-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 为当前用户固定本地 Harness 服务端口，使 Aqua 外观参数、自定义壁纸及其他按浏览器来源保存的界面设置在关闭应用后仍然有效。
- 保存并恢复窗口尺寸、位置及最大化状态；显示器布局变化后，不会恢复到屏幕之外。
- 修复切换自动更新选项时覆盖其他桌面设置的问题。
- 固定端口若临时被其他程序占用，本次启动会安全回退到可用端口，不影响后续恢复原有界面设置。

## 更新说明

升级后请重新设置一次所需外观；从 v0.0.4 开始，后续关闭并重新打开应用会恢复这些设置。原有配置、会话和插件数据仍会保留。

已开启“自动接收桌面更新”的用户会通过 GitHub Releases 收到本次更新，也可以手动下载安装包覆盖升级。

本版本尚未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从本仓库 Releases 下载并核对 SHA-256。

本项目是社区桌面封装，不是 DeepSeek 官方桌面客户端，也不代表 DeepSeek 官方背书。
