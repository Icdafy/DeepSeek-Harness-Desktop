# DeepSeek Harness v0.0.5

本次版本新增直接对话插件：不需要先打开工作区，即可与当前配置的模型聊天。

## 下载选择

- **Setup**：`DeepSeek-Harness-Setup-0.0.5-x64.exe`，适合日常安装和后续自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.5-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 新增内置“直接对话”插件，可在 **Settings → Plugins** 中开启或关闭。
- 侧边栏在工作区列表下方新增“对话区”，点击“新对话”即可创建无工作区会话。
- 无工作区会话使用独立输入框与完整消息流，直接复用当前模型、API Key 和会话发送管线。
- 最近创建的直接对话会保存在对话区中，重启应用后可继续打开。

## 更新说明

已开启“自动接收桌面更新”的用户会通过 GitHub Releases 收到本次更新，也可以手动下载安装包覆盖升级。原有模型配置、会话、工作区和插件数据会保留。

直接对话会话仍属于本地 Harness 数据，不会自动上传到 GitHub。若模型供应商需要联网调用，请按原有配置由本机直接访问。

本版本尚未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从本仓库 Releases 下载并核对 SHA-256。

本项目是社区桌面封装，不是 DeepSeek 官方桌面客户端，也不代表 DeepSeek 官方背书。
