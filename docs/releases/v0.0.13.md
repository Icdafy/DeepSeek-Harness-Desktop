# DeepSeek Harness v0.0.13

发布日期：2026-10-20

## 最新 Flash 模型

- Flash 统一使用 **`deepseek-flash`**，当前由 **DeepSeek-V4.1-Flash-1017** 提供服务，默认模型列表显示完整版本名称。
- 旧模型名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 对应模型已下线。本版在解析旧模型选择、加载旧模型列表和发送请求时自动转换为 `deepseek-flash`，不依赖旧名称转发。
- 调用方式、现有 API Key 和 Flash 计费方式不变。选择 DeepSeek Pro 或自定义模型时，继续使用对应配置。

核验依据：[DeepSeek API 官方模型说明](https://api-docs.deepseek.com/)、[2026-10-17 官方更新记录](https://api-docs.deepseek.com/updates/)。`deepseek-flash` 是官方持续更新的模型名，此处版本对应本次发布时的服务版本。

## 内置运行时

- 将 Harness 从 `0.2.1-alpha.2` 升级至 **`0.2.1-rc.2`**，即 2026-10-20 核验的官方 npm `latest` 版本，包含上游的 1017 模型适配。
- 重新适配 Aqua、直接对话、侧边栏和工作区补丁，保留工作区“完全删除”及缺失目录检查。
- 增加模型请求回归检查，覆盖标准模型名、两个旧 Flash 名称、流式请求体、模型能力及 Pro/自定义模型保留，使用模拟响应验证，无需 API Key。

上游发布：[dsh-v0.2.1-rc.2](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.2.1-rc.2)。

## 下载

- **Setup**：`DeepSeek-Harness-Setup-0.0.13-x64.exe`，支持覆盖安装和自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.13-x64.exe`，免安装启动。
- **SHA256SUMS.txt**：安装器和便携版的 SHA-256 校验值。
- `latest.yml` 与 `.blockmap`：供已有桌面客户端自动更新使用。

## 升级说明

配置、工作区、对话记录和外观设置继续使用原用户数据目录。升级后在模型选择器选择 **DeepSeek-V4.1-Flash-1017** 即可使用最新 Flash；历史 Flash 选择也会转换为标准模型名。现有 Pro 和自定义模型选择不会被强制切换。

运行时仍处于 developer preview，继续使用 V4 会话日志格式。升级前请备份用户数据；旧版 Harness 无法读取新写入的 V4 内容。

本项目是社区维护的桌面封装，不是 DeepSeek 官方桌面客户端。
