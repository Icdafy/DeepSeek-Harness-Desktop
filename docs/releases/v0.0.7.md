# DeepSeek Harness v0.0.7

本次版本调整了侧边栏层级，让“对话区”紧邻工作区显示，不再停留在侧边栏底部。

## 下载选择

- **Setup**：`DeepSeek-Harness-Setup-0.0.7-x64.exe`，适合日常安装和后续自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.7-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 将“对话区”上移到工作区正下方，使两个主要会话入口连续排列。
- 工作区与对话列表内容较多时仍各自保留可用的滚动空间。
- 收起侧边栏时继续保留工作区与直接对话的快捷操作布局。

## 更新说明

已开启“自动接收桌面更新”的用户会通过 GitHub Releases 收到本次更新，也可以手动下载安装包覆盖升级。原有模型配置、会话、工作区和插件数据会保留。

直接对话会话仍属于本地 Harness 数据，不会自动上传到 GitHub。若模型供应商需要联网调用，请按原有配置由本机直接访问。

本版本尚未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从本仓库 Releases 下载并核对 SHA-256。

本项目是社区桌面封装，不是 DeepSeek 官方桌面客户端，也不代表 DeepSeek 官方背书。
