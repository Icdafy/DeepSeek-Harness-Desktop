# DeepSeek Harness v0.0.6

本次版本统一了直接对话与工作区会话的完整交互，并收紧了桌面标题栏的视觉层级。

## 下载选择

- **Setup**：`DeepSeek-Harness-Setup-0.0.6-x64.exe`，适合日常安装和后续自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.6-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 标题栏移除左侧 Logo 与应用名称，仅保留右侧最小化、最大化和关闭按钮。
- 标题栏改为跟随主题的半透明磨砂背景，取消清晰分割线，并用柔和阴影过渡到主界面。
- “对话区”侧边栏改为工作区同款布局与主题，增加搜索、运行状态、重命名、分叉、归档和收起状态快捷操作。
- 直接对话不再使用简化输入框，完整复用工作区会话输入组件，包括模式选择、左下角加号与对话指令、Full access、模型选择、附件、队列等全部扩展位。
- 直接对话会话与工作区列表分离，不再重复出现在“未分组”或工作区搜索结果中。
- 启动和重启服务时会刷新前端模块缓存，覆盖升级后无需手动清理即可立即使用新版界面。

## 更新说明

已开启“自动接收桌面更新”的用户会通过 GitHub Releases 收到本次更新，也可以手动下载安装包覆盖升级。原有模型配置、会话、工作区和插件数据会保留。

直接对话会话仍属于本地 Harness 数据，不会自动上传到 GitHub。若模型供应商需要联网调用，请按原有配置由本机直接访问。

本版本尚未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从本仓库 Releases 下载并核对 SHA-256。

本项目是社区桌面封装，不是 DeepSeek 官方桌面客户端，也不代表 DeepSeek 官方背书。
