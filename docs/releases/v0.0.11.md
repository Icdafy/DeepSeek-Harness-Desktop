# DeepSeek Harness v0.0.11

Windows x64 桌面版：同步 DeepSeek Harness 官方 GitHub 最新更新，内置运行时从 `0.1.5-rc.1` 升级至 `0.2.1-alpha.2`。

## 官方同步基线

- 核验日期：2026-10-12。
- 官方仓库：[deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)。
- 最新发布合并：[d743267](https://github.com/deepseek-ai/deepseek-harness/commit/d743267388641bc76f17c45ce8b4c231aed1d32c)，2026-10-09，`release-0.2.1-alpha.2`。
- 本版使用官方 npm 发布的完整 `0.2.1-alpha.2` 依赖树，并锁定实际安装版本。

**本次内置的是上游 alpha 预览版。** 核验时官方 npm `latest` 为 `0.2.0-rc.2`；本版按“同步官方 GitHub 最新更新”的要求采用更新的 `alpha` 发布。

## 本版更新

- 同步上游模型发现与账号接入：DeepSeek API Key 路由在配置凭据后显示模型，凭据异常有明确反馈。
- 同步新会话创建规则：新会话创建使用当前预设的新 Session 和 Agent，避免复用旧空会话的预设。
- 同步会话工作目录管理、Web 自动化任务、插件管理、工具展示和子代理相关更新。实验性能力按上游插件配置启用。
- 重做“对话区”所需的输入框、侧边栏和工作区补丁，保留最新工作区归档筛选能力。
- 适配新版会话导航和引用管理，确保新建、打开、重命名、分叉与归档对话继续工作，并同步新的图标接口。
- 适配 Aqua 的 client-store 与新版 Cordis，移除已被上游废弃的运行时不变式依赖和导出。
- 构建时检查实际部署的 Harness 版本，防止打包旧运行时。

## 下载

- **Setup**：`DeepSeek-Harness-Setup-0.0.11-x64.exe`，支持覆盖安装和自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.11-x64.exe`，免安装启动。
- **SHA256SUMS.txt**：安装器和便携版的 SHA-256 校验值。
- `latest.yml` 与 `.blockmap`：供已有桌面客户端自动更新使用。

## 升级说明

模型配置、工作区、对话记录和外观设置继续使用原用户数据目录。上游仍处于开发者预览阶段；建议升级前备份数据，第三方插件可能需要适配新版接口。DeepSeek API Key 模型列表为空时，请先在 Settings → Models 配置凭据。

新版上游使用 **V4 会话日志格式**，并迁移受支持的历史会话。升级后新增的 V4 内容不能由旧版 Harness 读取；降级前需恢复升级前的数据备份。

上游迁移说明：[模型发现](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/docs/upgrade-guide/v0.2.1-alpha.1/deepseek-model-discovery/guide.zh.md)、[新会话](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/docs/upgrade-guide/v0.2.1-alpha.1/new-session-generations/guide.zh.md)、[工作目录](https://github.com/deepseek-ai/deepseek-harness/blob/d743267388641bc76f17c45ce8b4c231aed1d32c/docs/upgrade-guide/v0.2.1-alpha.1/working-directory/guide.zh.md)。
