# DeepSeek Harness v0.0.9

Windows x64 桌面版：同步官方最新候选版，完善对话管理。

## 下载

- **Setup**：`DeepSeek-Harness-Setup-0.0.9-x64.exe`，支持覆盖安装和自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.9-x64.exe`，免安装启动。
- **SHA256SUMS.txt**：安装器和便携版的 SHA-256 校验值。
- `latest.yml` 与 `.blockmap`：供已有桌面客户端自动更新使用。

## 本版内容

1. 将内置官方 Harness 从 `0.1.0-rc.6` 升级至 **`0.1.5-rc.1`**。包含新版模型支持、通用文件上传、右侧多标签与分栏预览、长会话性能优化，以及 Windows 路径、子进程和断线恢复修复。详细内容见[官方发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.5-rc.1)。
2. 左侧标题由“对话”改为 **“对话区”**。
3. 每条对话右侧常显 **“⋯”**，空白新对话也可操作。菜单提供 **重命名、完全删除**，保留分叉和归档。
4. 完全删除经确认后，移除该会话在本机的所有日志版本、派生缓存和工作区引用。服务保存记录后短暂重启，界面自动刷新；若有任务运行，会提示结束后重试，避免中断任务。
5. 适配官方新的本地鉴权、客户端模块和插件设置接口。Aqua 与直接对话开关位于 **Settings → Plugins → 桌面插件**；Aqua 外观选项仍位于 General。

## 上游核验与升级说明

- 本版锁定官方 `dsh-v0.1.5-rc.1` 发布内容（标签对应提交 `183f08e9c6dde7e36cd2318eaee70b0da08fb35e`）。核验时 master 为 `2377c272a8e839e0a84c9f0e623b867a1dce2014`，比发布标签多出的 7 次提交仅涉及 README 与翻译校对。
- 上游会将受支持的旧会话迁移至 **V3** 并保留旧日志。升级后的新增会话内容不能由旧版 Harness 降级读取，升级前可备份应用数据目录。
- “完全删除”删除所选会话记录；独立分叉对话、工作区文件以及可能被其他会话引用的共享附件文件不随之删除。
- 原有模型配置、工作区和外观设置继续使用原用户数据目录。已开启自动更新的客户端可通过本 Release 更新。

本项目是社区维护的桌面封装，不是 DeepSeek 官方桌面客户端。
