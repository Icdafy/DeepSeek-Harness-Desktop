# DeepSeek Harness v0.0.12

Windows x64 桌面版：工作区对话完全删除，以及启动时重建已移除目录的修复。

## 本版更新

- 左侧工作区每条对话的“⋯”菜单新增 **完全删除**，包括当前空白会话和已归档会话；关闭下方直接对话区后仍可使用。
- 完全删除经确认后直接移除本地会话文件，清理全部日志格式版本、所选会话的新版投影缓存、工作区成员/置顶/归档引用及派生搜索缓存，然后重新连接界面。
- 项目文件、其他对话、独立分叉和共享附件保留。运行中的任务会阻止删除，避免服务重启中断任务。
- 修复每次启动后历史工作目录重新出现的问题：启动导航可能为最近工作区创建空白会话，上游创建代码原先无条件执行 `mkdir(cwd)`，把用户已经移除的目录重新建回。本版改为检查目录存在且为文件夹，目录缺失时提示重新选择工作区并保留历史记录。
- 增加真实桌面 UI 回归检查：启动不重建目录、空白工作区会话菜单、取消删除、磁盘文件删除、相邻会话和项目文件保留、缓存清理与刷新后的持久性。

## 下载

- **Setup**：`DeepSeek-Harness-Setup-0.0.12-x64.exe`，支持覆盖安装和自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.12-x64.exe`，免安装启动。
- **SHA256SUMS.txt**：安装器和便携版的 SHA-256 校验值。
- `latest.yml` 与 `.blockmap`：供已有桌面客户端自动更新使用。

## 升级说明

运行时继续使用 `@deepseek-ai/dsh@0.2.1-alpha.2` 和 V4 会话日志格式。配置、工作区、对话记录和外观设置继续使用原用户数据目录。

历史工作目录已被移除时，请通过“选择工作区”选择现有文件夹；已有会话记录保留。此前已经被旧版重新创建的目录不会自动删除，以免影响其中后来保存的文件。

本项目是社区维护的桌面封装，不是 DeepSeek 官方桌面客户端。
