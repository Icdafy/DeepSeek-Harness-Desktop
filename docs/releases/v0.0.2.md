# DeepSeek Harness v0.0.2

本次版本完成产品名称与窗口外观统一，并加入面向每位用户的桌面自动更新能力。

## 下载选择

- **Setup**：`DeepSeek-Harness-Setup-0.0.2-x64.exe`，适合日常安装和后续自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.2-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 应用名称更新为 **DeepSeek Harness**。
- 应用图标改为白底、DeepSeek 官方黑色鲸鱼图案。
- 删除 File、Edit、View、Help 原生菜单栏。
- 标题栏、应用名称和 Windows 窗口按钮会跟随当前浅色、深色或系统主题。
- 在 **Settings → General** 中新增“自动接收桌面更新”插件，默认开启，可随时关闭或手动检查。
- 开启后，客户端会读取本仓库正式 GitHub Release；发现新版后自动下载，并允许立即安装或退出时安装。
- 从 v0.0.1 升级时会迁移旧应用数据目录，保留现有配置和会话。

## 更新说明

只有本仓库正式发布的 Release 会触发客户端更新。每台电脑各自连接 GitHub，不依赖开发者电脑的 IP，也不需要自建推送服务器。

v0.0.1 尚未内置更新模块，因此 v0.0.1 用户需要手动下载安装 v0.0.2 一次；从 v0.0.2 开始，后续正式 Release 才能自动送达。

本版本尚未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从本仓库 Releases 下载并核对 SHA-256。

本项目是社区桌面封装，不是 DeepSeek 官方桌面客户端，也不代表 DeepSeek 官方背书。
