# DeepSeek Harness v0.0.8

本次版本重点改善桌面端在不同网络环境下检查和接收更新的稳定性，并让失败原因更容易判断。

## 下载选择

- **Setup**：`DeepSeek-Harness-Setup-0.0.8-x64.exe`，适合日常安装和后续自动更新。
- **Portable**：`DeepSeek-Harness-Portable-0.0.8-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 更新检查改为直接读取 GitHub Releases 的 `releases/latest/download/latest.yml`，减少 Atom Feed 与 Latest Release 探测造成的额外网络请求和失败点。
- 检查更新和下载安装包遇到短暂断连时会自动重试两次。
- 网络失败时显示中文排查提示，明确提醒检查系统代理、防火墙以及当前网络能否访问 GitHub。
- 保留 `latest.yml` 中 SHA-512 摘要校验和发布页 SHA-256 校验文件。

## 网络说明

v0.0.8 能改善 GitHub 部分接口不可达、连接重置和短暂超时等情况。如果当前网络完全无法访问 GitHub 域名或 Release 下载资源，客户端仍无法仅靠 GitHub Releases 完成自动更新；这种场景需要启用可用的系统代理，或由发布者另外部署自有对象存储/CDN 更新源。

已开启“自动接收桌面更新”的 v0.0.7 用户会通过 GitHub Releases 收到本次更新，也可以手动下载安装包覆盖升级。原有模型配置、会话、工作区和插件数据会保留。

本版本尚未使用商业代码签名证书，Windows SmartScreen 可能提示未知发布者。请只从本仓库 Releases 下载并核对 SHA-256。

本项目是社区桌面封装，不是 DeepSeek 官方桌面客户端，也不代表 DeepSeek 官方背书。
