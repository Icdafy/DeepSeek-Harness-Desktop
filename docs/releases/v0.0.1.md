# DeepSeek Harness Desktop v0.0.1

首个 Windows x64 桌面预览版本。

## 下载选择

- **Setup**：`DeepSeek-Harness-Desktop-Setup-0.0.1-x64.exe`，适合日常安装使用。
- **Portable**：`DeepSeek-Harness-Desktop-Portable-0.0.1-x64.exe`，无需安装。
- **SHA256SUMS.txt**：用于校验下载文件完整性。

## 本版内容

- 将 DeepSeek Harness Web UI、本地服务和运行时完整封装为 Electron 桌面应用。
- 内置 Node.js 24.14.0、`@deepseek-ai/dsh@0.1.0-rc.6` 和 pnpm 11.22.0。
- 服务仅绑定 `127.0.0.1`，端口由系统动态分配。
- 支持单实例、启动检测、服务重启、日志目录和退出时进程清理。
- 用户配置与会话保存在 `%APPDATA%\DeepSeek Harness Desktop\dsh-home`，升级和默认卸载不会删除。

## 已知限制

- 仅提供 Windows 10/11 x64 构建。
- 本版本没有商业代码签名，Windows SmartScreen 可能提示未知发布者。请从本仓库下载并核对 SHA-256。
- 上游 DeepSeek Harness 仍处于 developer preview，后续可能存在不兼容变更。
